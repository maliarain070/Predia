# PREDIA Multi-page Website

A front-end starter project for PREDIA.

## Requirements

- Node.js
- npm
- Visual Studio Code

## Installation

Open the project folder in your terminal.

Run:

npm install

## Start the website

Run:

npm run dev

Open the local address displayed in your terminal.

## Build for production

Run:

npm run build
